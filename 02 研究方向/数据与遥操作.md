## 先沿着数据流程理解这些论文

采集到一段“成功视频”不代表已有高质量训练数据：还要确定机器人动作是否可信、是否覆盖目标任务、换到真实硬件能否执行。可以按下面四步阅读：先用简介理解问题与方法，再进入主卡查实验设置、出处、日期和机构，最后回到原文验证结论

### 1. 先把人的示范变成可信的机器人记录

- [[03 论文卡片/08_数据与遥操作/Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware|P191 · ALOHA／ACT]]：主从双臂采集真实动作，策略预测动作块以减少误差累积。适合先理解相机、动作与时间戳怎样组成可训练的一条示范；双臂夹爪成绩不代表已经适配 DH116
- [[03 论文卡片/08_数据与遥操作/Universal Manipulation Interface - In-The-Wild Robot Teaching Without In-The-Wild Robots|P193 · UMI]]：用便携手持夹爪采集，再通过相对轨迹和延迟匹配部署到机器人。适合比较“把机器人带到现场”和“只带采集接口”的成本与动作可靠性
- [[03 论文卡片/08_数据与遥操作/Open-TeleVision - Teleoperation with Immersive Active Visual Feedback|P194 · Open-TeleVision]]：把头手跟踪、主动双目反馈和动作映射连起来，改善操作者看不清、深度感不足的问题。读实验时区分操作者表现、子步骤成功率和整回合自主完成
- [[03 论文卡片/08_数据与遥操作/ACE - A Cross-platform and visual-Exoskeletons System for Low-Cost Dexterous Teleoperation|P195 · ACE]]：外骨骼负责手腕、相机负责手指，再按目标机器人适配。适合研究如何把通用采集端与 DH116 的可达范围、耦合和标定分开

### 2. 再研究如何生成更多可执行示范

- [[03 论文卡片/08_数据与遥操作/DexMimicGen - Automated Data Generation for Bimanual Dexterous Manipulation via Imitation Learning|P145 · DexMimicGen]]：从少量源示范按物体位姿和双臂时序重组，在仿真中执行成功后保留。它解决扩增，不解决源示范完全缺失；数字孪生真机验证范围有限
- [[03 论文卡片/08_数据与遥操作/DexImit - Learning Bimanual Dexterous Manipulation from Monocular Human Videos|P200 · DexImit]]：单目视频经过手物重建、子任务安排、轨迹合成和扩增，形成学习数据。优先读“重建成功”“仿真策略成功”“真机展示”分别证明什么
- [[03 论文卡片/08_数据与遥操作/DexMan - Learning Bimanual Dexterous Manipulation from Human and Generated Videos|P204 · DexMan]]：用重建场景和接触奖励，在仿真中修正完整上肢的参考动作。与 DexImit 对照时注意它没有真机验证，正式录用状态仍待核验
- [[03 论文卡片/08_数据与遥操作/SPIDER - Scalable Physics-Informed Dexterous Retargeting|P209 · SPIDER]]：通过物理采样修正几何重定向轨迹，减少每条轨迹单独强化学习的成本。适合研究多指接触，但开环回放和浮动手生成不保证臂手可达或自主恢复

### 3. 决定哪些数据值得进入策略训练

- [[03 论文卡片/08_数据与遥操作/Robot Data Curation with Mutual Information Estimators|P205 · DemInf]]：用状态—动作互信息兼顾动作多样性和可预测性，估计示范相对质量。无需把质量等同于成功标签，但评分和策略收益仍需分别验证
- [[03 论文卡片/08_数据与遥操作/Quality over Quantity - Demonstration Curation via Influence Functions for Data-Centric Robot Learning|P206 · Quality over Quantity／QoQ]]：近似估计每条轨迹能否帮助模型拟合目标验证示范，整条筛选以保留前后动作。适合研究“对当前抓取任务有用”，也要警惕验证集遗漏新抓法
- [[03 论文卡片/08_数据与遥操作/TUCO - Curating Simulation Demonstrations for Sim-to-Real Robot Policy Co-Training|P207 · TUCO]]：把单条效用和集合互补性放在目标执行影响空间中共同选择，关注仿真数据怎样帮助真机。它是联合训练前的数据组成设计，不是部署时的失败恢复

### 4. 将问题反馈到下一回合采集

- [[03 论文卡片/08_数据与遥操作/Closing the Loop in Teleoperation - Episode-Level Data Quality Assessment and Feedback for High-Quality Demonstration Collection|P208 · Closing the Loop／DQAF]]：把视频语义与机器人运动日志组合成回合后的改进建议，帮助人减少停顿和反复修正。三名新手的探索性研究尚不能证明下游策略一定改善，反馈等待也不是实时控制延迟

对现有机械臂、DH116 与 D435i，可先从同步记录与离线回放建立基线，再比较等预算下的随机子集、人工质量筛选和模型相关筛选；接触可达性、动作映射、真实摩擦和最终闭环成功率要逐项验证。这是本库提出的研究顺序，不是上述论文已经共同验证的系统
