# 机器人数据采集与数据质量

本专题围绕一个问题：怎样以可承担的采集成本，得到**能训练出可靠机器人策略**的数据，而不仅是越来越多的视频。正文依据本轮全文核读及已有主卡，论文报告、资源现状和本库方案分别标明

关联：[[02 研究方向/机器人遥操作与动作重定向]] · [[02 研究方向/机器人数据与遥操作技术路线对比]] · [[02 研究方向/DH116机器人数据与遥操作研究方案]]

## 先建立完整链条

人类任务示范 → 遥操作接口／离线动作转换 → 记录机器人观察、命令与真实状态 → 同步和质量检查 → 按 episode 整理训练集 → 行为克隆／动作块／扩散策略／VLA → 独立闭环测试 → 标注失败与人工纠正 → 再次采集和训练

**示范**是一次有任务和起止边界的行为记录；**episode**是其数据单元；**动作标签**必须说明是人类意图、控制目标还是实际发出的机器人命令。三者混用会使训练目标与真实执行错位。人类示范通过有目的地到达任务相关状态，通常比无目标随机动作更快获得有用接触；但人也会抖动、偏置和犯错，需要独立验证

## 数据从哪里来，各有什么代价

1. **机器人直接示范**：主从臂、XR、视觉手追踪等接口实际控制机器人，保存观察、动作和状态；[[03 论文卡片/08_数据与遥操作/Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware|P191 · ALOHA / ACT]]、[[03 论文卡片/08_数据与遥操作/GELLO - A General, Low-Cost, and Intuitive Teleoperation Framework for Robot Manipulators|P192 · GELLO]]、[[03 论文卡片/08_数据与遥操作/OPEN TEACH - A Versatile Teleoperation System for Robotic Manipulation|P151 · OPEN TEACH]] 是系统入口。优点是动作可执行性直接受硬件约束，代价是机器人时间、同步和操作者训练
2. **手持／可穿戴采集**：[[03 论文卡片/08_数据与遥操作/Universal Manipulation Interface - In-The-Wild Robot Teaching Without In-The-Wild Robots|P193 · UMI]]、[[03 论文卡片/04_灵巧操作/DexUMI - Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation|P086 · DexUMI]]、[[03 论文卡片/08_数据与遥操作/DexCap - Scalable and Portable Mocap Data Collection System for Dexterous Manipulation|P009 · DexCap]] 让操作员离开固定机械臂采集，扩大场景；需要额外手持器、手套或追踪器，仍需把几何和外观转换到部署接口
3. **人类视频转换**：[[03 论文卡片/08_数据与遥操作/DexImit - Learning Bimanual Dexterous Manipulation from Monocular Human Videos|P200 · DexImit]]、[[03 论文卡片/08_数据与遥操作/DexMan - Learning Bimanual Dexterous Manipulation from Human and Generated Videos|P204 · DexMan]]、[[03 论文卡片/04_灵巧操作/Hand2Robot - Object-Centric 4D Hand Reconstruction from Human Demonstrations for Robotics|P184 · Hand2Robot]]–[[03 论文卡片/03_双臂协作/DemoBot - Efficient Learning of Bimanual Manipulation with Dexterous Hands From Third-Person Human Videos|P190 · DemoBot]] 用手物重建或意图模型提供监督；原始视频不自带关节控制命令，转换误差要单独审计
4. **仿真生成**：[[03 论文卡片/08_数据与遥操作/MimicGen - A Data Generation System for Scalable Robot Learning using Human Demonstrations|P202 · MimicGen]]、[[03 论文卡片/08_数据与遥操作/DexMimicGen - Automated Data Generation for Bimanual Dexterous Manipulation via Imitation Learning|P145 · DexMimicGen]] 用少量源示范扩增，[[03 论文卡片/10_基准测试与数据集/RoboTwin 2.0 - A Scalable Data Generator and Benchmark with Strong Domain Randomization for Robust Bimanual Robotic Manipulation|P172 · RoboTwin 2.0]] 用专家程序和随机化生成，[[03 论文卡片/08_数据与遥操作/SPIDER - Scalable Physics-Informed Dexterous Retargeting|P209 · SPIDER]] 用物理采样修正；模拟成功、模型误差和真实执行属于不同评价环节
5. **跨机构数据**：[[03 论文卡片/08_数据与遥操作/BridgeData V2 - A Dataset for Robot Learning at Scale|P203 · BridgeData V2]]、[[03 论文卡片/10_基准测试与数据集/DROID - A Large-Scale In-The-Wild Robot Manipulation Dataset|P010 · DROID]]、[[03 论文卡片/10_基准测试与数据集/Open X-Embodiment - Robotic Learning Datasets and RT-X Models|P002 · Open X-Embodiment]] 提供公开数据或统一读取接口，适合先学习数据管线；传感器、任务、本体与采集者分布仍不同，不能简单合并关节角

## 最小数据结构：本库建议，不是所有论文共有格式

| 数据层 | 建议保存的内容 | 为什么保留 |
|---|---|---|
| 原始观测 | RGB、有效深度、相机内外参及时间戳；若有则保存 IMU | 后续可重新估手部、物体、同步误差；深度缺失不能静默填零 |
| 动作与状态 | 人类参考、映射目标、实际发出命令、机器人反馈，各自时间戳和单位 | 区分意图、控制与执行；未知单位不能当物理量 |
| 任务与阶段 | 任务描述、物体身份、接近／接触／搬运／释放阶段、左右手角色 | 支持动作条件、接触审计与双臂对齐 |
| 模式与结果 | 遥操作／自主／接管状态，成功、失败类型、纠正区间、结束理由 | 保留失败价值，又不把错误动作无差别当正例 |
| 来源与版本 | 采集批次、匿名操作者、标定版本、机器人侧别与模型版本、转换流程 | 防止跨批次泄漏、左右手混用或标签失去来源 |

这些字段可以转换到 robomimic HDF5、RLDS、LeRobot 等接口，但“格式兼容”不代表动作语义、单位、时钟和本体已经对齐。原始数据与转换版本分开保存，失败和不可恢复缺帧标记保留，避免不可逆地抹掉研究证据

## 失败与纠正轨迹怎样保留

失败并非全部丢弃，也不应全部作为正确动作加入行为克隆。先按轨迹结果和阶段标注：感知丢失、映射越界、执行器异常、接触失败、目标未完成。失败前的有效接近、人工成功纠正和无效重复应保留可区分的掩码／标签

[[03 论文卡片/08_数据与遥操作/Quality over Quantity - Demonstration Curation via Influence Functions for Data-Centric Robot Learning|P206 · QoQ]] 用成功与失败策略执行分别提供正／负向筛选依据；[[03 论文卡片/08_数据与遥操作/Forward and Reverse Teleoperation for Dexterous Manipulation and Human Intervention|P148 · DITTO-X]] 提供接管接口与记录；[[03 论文卡片/08_数据与遥操作/Closing the Loop in Teleoperation - Episode-Level Data Quality Assessment and Feedback for High-Quality Demonstration Collection|P208 · DQAF]] 反馈面向操作员。它们都不能替代对纠正数据训练后的独立测试。尤其不能为了“轨迹平滑”把必要的接触停顿和真实纠正全部删掉
