# DH116 灵巧手控制 Demo

**一个文件夹、一份说明、双击启动。** 在同一个中文控制台中，设置 DH116 **右手**六个电机的 SDK 角度和运动速度。无需 VS Code，不需要编写 Python 或修改动作配置。

> 这是会驱动真实设备的程序。启动前固定手部、留足六轴 HOME 全行程空间、准备独立停机/断电措施，并退出 LHandPro。程序只有在输入一次 `YES` 后才连接并进行 HOME；软件 STOP 不等于硬件急停。

## 1. 项目介绍

```text
DH116_Controller_Demo/
├── README.md             本说明
├── 启动控制.bat           日常使用：双击这个文件
├── 首次安装.bat           第一次使用或换电脑时运行
├── requirements.txt      实际需要的Python依赖
├── app/                  中文界面、必要控制模块、Mock及离线测试
├── config/               右手设备配置、原生角度设置
├── vendor/               自行取得并放置的厂家SDK
└── licenses/             来源记录、许可说明
```

首次安装生成本目录自己的 `.venv`。运行时的诊断记录放入 Windows 隐藏目录 `.runtime/logs/`，不会把原开发工程的实验历史复制进来。

## 2. 控制效果与证据边界

- 支持 M1–M6 单轴自定义角度、六轴不同角度 `POSE`、统一角度 `ALL`、返回零目标 `RETURN`，以及会话内修改 `SPEED`。
- 延用开发工程已经运行过的初始化、六轴 HOME、位置模式、原生 SDK 角度 setter、指定电机 MOVE、六轴反馈/报警监测和清理链。
- 用户已确认 M3 的 0°、10°、20°、30°原生角度真机动作成功，30°对应 SDK raw3750。
- 原开发工程曾完成 M1–M4 的400→800→1200→1600 raw协同控制及RETURN；这是原控制链证据，**不是本简洁版、全部六轴角度或所有速度的真机验收**。具体历史结果和运行标识不随公开包上传。
- 本整理版只完成离线/Mock测试。界面“完成”表示 SDK 反馈达到本次目标，不代表物理角度已标定、机械绝对停止或方块已稳定夹住。

**POSE、ALL和RETURN是逐轴顺序动作，每轴反馈完成后才执行下一轴，不是同步运动。** 发生错误后停止剩余动作；不保证已执行的轴自动回滚。

## 3. 需要准备什么

| 项目 | 要求 |
|---|---|
| 电脑 | Windows 10/11 x64，64位Python 3.10或更新版；建议使用正常安装版Python |
| 设备 | DH116右手、厂家规定供电、机械固定、独立断电/停机条件 |
| CANFD适配器 | 当前配置为 Mini CANFD-I / Com Equipment CANFD Analyser，VID:PID为A8FA:8598，WinUSB驱动 |
| 通信参数 | Node ID 1、Nominal 1000000、Data 5000000；换设备前核实其实际配置 |
| 厂家SDK | 获授权的Windows x64 LHandProLib DLL、对应Python包和适配器包 |
| 运行库 | 厂家DLL所需Microsoft Visual C++ 2015–2022 x64运行库；缺失时从Microsoft官方安装 |
| 网络 | 首次安装Python依赖时需要联网，日常控制无需联网 |

### 准备SDK：只需做一次

本包**没有包含未经明确许可的厂家DLL或Python wrapper**。请从[厂家官方资料入口](https://zcnrg1e5hv0a.feishu.cn/wiki/KN1SwOqSxidq3dkxBuDcCLoinch)取得SDK，按以下对应位置放置；只拷贝自己获授权使用的文件，不删除相应许可与署名。

| 官方SDK中的文件/目录 | 放入本项目 |
|---|---|
| `x64/bin/LHandProLib.dll` | `vendor/sdk/bin/LHandProLib.dll` |
| `x64/share/LHandProLib/examples/CANFD_python/lhandprolib_python_sdk/` | `vendor/sdk/python/lhandprolib_python_sdk/`，整个包，保留controller/defaults/loader等依赖 |
| 同级 `gsusb_canfd/` | `vendor/sdk/python/gsusb_canfd/`，整个包及其LICENSE |
| 厂家确认必需且允许使用的依赖DLL | `vendor/sdk/bin/`；运行库优先通过官方安装程序安装 |

不要混用x86、调试版DLL或其他版本的wrapper。pyusb和libusb通过首次安装的依赖包提供；本工具不安装或替换系统驱动，也不自动启动LHandPro。不要为了控制此手而安装其他CAN品牌驱动。

公开仓库只提供不含设备SN的 `config/device.example.json`。首次安装会生成 `config/device.local.json`；也可自行复制示例为该文件，并将 `adapter_serial` 改为本机设备管理器中USB InstanceId末段，确认Node ID和两档bitrate后保存。`device.local.json` 被Git忽略，**不要上传或截图公开真实SN**。

未填写本地配置时不允许连接真机；Mock只使用示例和合成适配器标识，不读本机SN。更换适配器时更新本地配置；原控制链的单一VID/PID候选选择与多候选拒绝规则不变。

## 4. 第一次使用

1. 将整个文件夹复制/解压到可写目录。不要只复制 `启动控制.bat`。
2. 安装64位Python 3.10+，勾选“添加到PATH”；按上一节放好厂家SDK。
3. 双击 **`首次安装.bat`**。它创建自己的虚拟环境、安装依赖、生成被Git忽略的 `config/device.local.json` 并静态检查SDK文件；按上一节填写本机适配器SN。它不连接设备、不运动、不自动修改驱动，不需要主动申请管理员权限。
4. 如果提示缺SDK、Python版本/位数或运行库，按提示处理后再运行首次安装。SDK尚未补齐时仍可通过下方Mock模式学习命令。
5. 按厂家要求接线、供电和固定，确认WinUSB驱动正常、活动空间充足、独立断电可用。
6. 完全退出LHandPro和其他占用适配器的程序。不要同时运行两个控制会话。
7. 双击 **`启动控制.bat`**。

## 5. 启动程序

日常使用：**双击 `启动控制.bat`**。

启动后输入一次速度，例如：

```text
请输入运动速度 SPEED：
SPEED: 500
当前速度：500
```

随后按提示输入一次 `YES`，授权本次会话。程序连接并初始化成功后执行六轴 HOME 和位置模式准备；只有全部准备成功才显示“当前六轴角度控制已就绪”。此后不再每条命令重新连接、重新HOME或询问YES。

输入提示为 `DH116 >`，只输入命令本身，不需要再输入提示符。

### 没有设备：先用模拟模式

在本目录的PowerShell或命令提示符中运行：

```powershell
.\启动控制.bat --mock
```

明确显示“模拟模式”，不加载厂商SDK、不访问USB，所有范围、位置与角度均为合成数据，不能当作真机标定。Mock模式不要求已放入SDK。

需要定位错误时，显式使用调试模式：

```powershell
.\启动控制.bat --debug
```

仅做安装文件静态检查、不连接设备：

```powershell
.\启动控制.bat --check
```

## 6. 控制命令

| 命令 | 功能 |
|---|---|
| `M1 20` | 拇指侧摆，目标SDK角度20° |
| `M2 10` | 拇指屈曲，目标SDK角度10° |
| `M3 30` | 食指屈曲，目标SDK角度30° |
| `M4 25` | 中指屈曲，目标SDK角度25° |
| `M5 15` | 无名指屈曲，目标SDK角度15° |
| `M6 20` | 小指屈曲，目标SDK角度20° |
| `M3 7.5` | 小数角度输入 |
| `SPEED 300` | 修改后续所有动作的会话速度，不改变正在进行的动作 |
| `POSE M1=20 M2=10 M3=40 M4=30 M5=20 M6=15` | 各轴不同目标，按M1→M6逐轴执行，逐轴等待反馈 |
| `POSE M3=20 M4=15` | 只操作指定轴；其他轴保留既有目标 |
| `ALL 10` | 六轴分别设置10°，逐轴执行；不是相同raw或硬件同步 |
| `RETURN` | 六轴依次返回零角度目标，已在SDK零参考的轴跳过；**不是重新HOME** |
| `STATUS` | 显示当前速度、六轴SDK角度/raw位置/目标/status/alarm |
| `HELP` | 显示菜单 |
| `STOP` | 中止会话，尝试软件停止→断使能→关闭；不自动张开 |
| `EXIT` | 结束会话，执行相同清理；不自动RETURN |

命令不区分大小写。POSE/ALL先查询并检查全部目标，各轴范围不同；任一输入不合法时整条命令不派发。执行过程中若SDK/反馈出错，则停止后续轴，不能回滚前轴。单轴使用 `set_target_angle(id,angle)`、`move_motors(id)`，不会由界面调用广播MOVE；厂商DLL内部可能使用含六轴字段的报文，不承诺线缆层完全轴隔离。

### 速度与角度的含义

- SPEED沿用 `set_position_velocity(id, int)`，单位为**SDK位置计数/秒（当量/秒）**，不是度/秒。更改后对单轴、POSE、ALL、RETURN生效；HOME速度仍由原有厂家流程决定。
- 速度必须是正整数；当前1–65535仅是C整数和CANFD两字节表示容量保护，**不是已确认的SDK/固件最大速度或机械许可**。本地资料没有明确本固件最大速度及SDK到线缆速度字段换算，不应用未知极大数值尝试真机。
- 每次MOVE前检查SDK返回码和速度缓存读回一致性。缓存一致不等于设备确认或实际物理速度验证；设备拒绝、读回不一致、报警或通信异常都会中止。
- 各轴角度范围通过原生 `get_limit_target_angle` 查询，角度→raw由SDK完成，不使用左手仿真或历史单点比例外推；负角度方向/零点语义尚未确认，当前拒绝。
- SDK角度和允许参数范围不等于物理关节角度标定或机械安全行程。本页角度示例仅示范输入，实际需在该轴SDK范围内。

## 7. 实际操作例子

以下在 `DH116 >` 后输入；每条运动结束并读到反馈后，再输入下一条。

**食指弯曲，然后张开并退出：**

```text
M3 30
STATUS
RETURN
EXIT
```

**按顺序调整六个电机（六轴对应五根手指，拇指占两轴）：**

```text
M1 20
M2 10
M3 30
M4 25
M5 15
M6 20
```

**六轴设置不同角度，然后返回零目标：**

```text
POSE M1=20 M2=10 M3=40 M4=30 M5=20 M6=15
STATUS
RETURN
```

**改变后续弯曲速度：**

```text
SPEED 300
M3 30
SPEED 600
M3 45
RETURN
EXIT
```

这些是操作示例，不代表全部角度、速度及组合已通过真机验证。不提供单条动作临时速度覆盖语法；使用 `SPEED 数值` 改会话速度。

## 8. 常见问题

| 提示/现象 | 怎么处理 |
|---|---|
| 缺Python或版本/位数不符 | 安装64位Python 3.10+，重新执行首次安装 |
| 尚未安装环境 | 双击首次安装；不要从原开发工程复制`.venv` |
| 缺SDK、DLL位数错误 | 按第3节补齐相同版本x64 SDK；无需重新编写控制代码 |
| DLL缺VCRUNTIME/MSVCP | 从Microsoft官方安装Visual C++ 2015–2022 x64运行库 |
| 连接失败/找不到适配器 | 检查接线、供电、WinUSB绑定；关闭LHandPro；多适配器时核对配置 |
| SDK Error 7/通信或反馈异常 | 本次动作未确认完成。先确认物理状态与独立停机；检查线缆、供电及占用，再查看内部记录，不要连续重试未知故障 |
| 角度不合法 | 使用该轴SDK实际查询范围；不要把其他轴范围套用过来；输入有限非负数 |
| 速度不合法 | 输入整数，例如500，而非`500.0`；零、负数、NaN等会被拒绝 |
| 停止未确认 | 不能根据关闭成功认定机械停止；现场确认，必要时使用独立断电 |
| 无意输入STOP/EXIT | 会结束会话，不自动回零；想先张开则先RETURN再EXIT |
| 窗口退出 | 批处理保留提示和“按任意键”，不会直接闪退 |

详细记录默认位于 `.runtime/logs/`，Windows资源管理器可勾选“隐藏的项目”查看。按次保存配置、状态CSV、原始帧及事件JSONL；每个主日志1MiB、最多3份轮转副本，最多保留5次已完成会话。中断会话不会被自动当作已完成删除，可定期人工检查；日志轮转可能淘汰较早数据，不是完整无限期归档。

`--debug`额外显示内部细节。SDK返回错误、日志/采集故障和清理失败保留记录，不伪造“已经安全停止”。日志故障时原有独立停止/清理路径仍优先执行。软件命令只在提示处接收，动作中可用Ctrl+C尝试清理；**独立硬件停机始终由现场掌握**。

## 9. 注意事项

- 初始HOME涉及六轴，可能大幅运动。不要把RETURN=0与厂家HOME混为一谈，也不要把软件0自动当作物理零位。
- 无物体确认动作后再探索轻质物体；本包不证明稳定抓取、力控制或接触检测能力。
- 报警、持续非预期运动、目标突变或真实反馈超时仍会中止。不能通过简洁界面绕过保护。
- 不要同时启动多个控制程序；实际适配器是否可用仍以真实open结果为准。
- 复制到另一台电脑时保留`app/config/vendor/licenses`，从示例重建该电脑自己的 `config/device.local.json`；不要复制上一台的设备私有配置。**不要复用旧`.venv`和`.runtime`**，应重新运行首次安装，并取得/放置获授权SDK、安装该电脑的WinUSB与运行库。
