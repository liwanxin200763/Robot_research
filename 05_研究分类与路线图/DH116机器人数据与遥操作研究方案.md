# DH116机器人数据与遥操作研究方案

本页是根据文献提出的**后续实验设计**，不表示已实现或已测出论文级结果。当前先利用 D435i、DH116 模型与离线记录建立可检验的数据基础；本轮仅完成文献研究和文件维护，没有操作真实机器人

平台边界依据 2026-10-15 只读项目说明：DH116 右手为六主动轴、十一总自由度，当前整手／多轴运动尚未完成验收，根因仍未知；后续三指目标主要是拇指侧摆／屈曲、食指与中指。左手仿真资产不能当右手真机标定，机械臂联动和双臂同步也不能默认已经具备

## 方案 A：低成本基础版——可解释的离线手形映射

**参考**：[[02_论文/08_数据与遥操作/AnyTeleop - A General Vision-Based Dexterous Robot Arm-Hand Teleoperation System|P196 · AnyTeleop]] 的向量重定向、[[02_论文/08_数据与遥操作/Dexterous Imitation Made Easy - A Learning-Based Framework for Efficient Dexterous Manipulation|P199 · DIME]] 的 RGB 采集、[[02_论文/08_数据与遥操作/DexPilot - Vision Based Teleoperation of Dexterous Robotic Hand-Arm System|P198 · DexPilot]] 的捏合关系，结合 [[02_论文/08_数据与遥操作/What Matters in Learning from Offline Human Demonstrations for Robot Manipulation|P201 · robomimic]] 的数据／测试隔离思路

**硬件**：现有 D435i＋电脑；DH116 的可靠运动学与耦合模型。早期不需数据手套、XR 或真实机械臂运动。模型方向和关节范围缺失时先标未知，不能从左手模拟值推出右手命令

**软件模块**：RGB-D 录制及统一时间戳 → 人手关键点与置信度 → 人／相机／手模型坐标对齐 → 主动轴受限优化 → 低通与失踪状态 → 三维回放和结构化日志。深度可增加公制线索，但不是接触力传感器

**最小可验证实验（拟议）**：录张手、捏合、包络抓三类动作，按不同日期／视角分训练与留出批次；同一输入比较简单角度复制、指尖目标优化与加入耦合约束三种映射。测指尖相对误差、越界／饱和、抖动、深度缺失和计算耗时，保存每次失效原因。尚未标定的物理量不填“精度提升多少毫米”

**主要风险**：人手遮挡、拇指方向、深度对齐和耦合模型错误。先区分感知误差与映射误差，不能只看最终动画。真机后续仅在正式验收通过后讨论低速单独测试

**创新空间**：低成本相机下，利用追踪置信度与可控轴约束选择可信目标。仅重新接入 MediaPipe 或复现优化器不是创新；需证明在相同输入、算力和模型下，对遮挡或接触阶段有可重复增益

## 方案 B：中等复杂度版——有来源和质量证据的示范数据管线

**参考**：[[02_论文/08_数据与遥操作/Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware|P191 · ALOHA / ACT]]／[[02_论文/08_数据与遥操作/GELLO - A General, Low-Cost, and Intuitive Teleoperation Framework for Robot Manipulators|P192 · GELLO]] 的实际动作记录、[[02_论文/08_数据与遥操作/DexCap - Scalable and Portable Mocap Data Collection System for Dexterous Manipulation|P009 · DexCap]] 的同步采集、[[02_论文/08_数据与遥操作/Robot Data Curation with Mutual Information Estimators|P205 · DemInf]] 的统计筛选、[[02_论文/08_数据与遥操作/Closing the Loop in Teleoperation - Episode-Level Data Quality Assessment and Feedback for High-Quality Demonstration Collection|P208 · DQAF]] 的回合后反馈，结合 [[02_论文/08_数据与遥操作/Forward and Reverse Teleoperation for Dexterous Manipulation and Human Intervention|P148 · DITTO-X]] 的接管模式区分

**硬件**：保留 D435i；后续需要已验收的 DH116 状态反馈与机械臂接口。XR／主臂是可选扩展，不作为最初完成数据结构的前提；新增第二视角或第二臂前先测同步误差

**软件模块**：统一 episode 管理 → 原始观察／人类意图／目标动作／已发命令／实际反馈分层 → 模式、单位、标定版本、左右侧别记录 → 缺帧与状态审计 → 失败和纠正区间标注 → 数据集转换与训练读取器 → 质量报告。双臂预留公共时钟和共享物体坐标，而非仅把两个独立文件拼接

**最小可验证实验（拟议）**：先对离线回放注入可控时间偏差、丢帧和追踪失效，验证系统能定位而非静默补齐。硬件条件完成后，固定一种刚体抓放任务、固定采集时间预算，比较人工复核、规则检查与接触阶段检查选出的等量数据；用同一小模型和相同训练步数评估

按采集批次、物体和操作者分组划分数据，不按相邻视频帧随机切分。独立报告数据可用率、每条有效示范耗时、标注一致性、策略成功率及置信区间。成功率是后续新执行的结果，不能由训练重放误差代替

**主要风险**：目标值与实际反馈时钟不一致、未知单位、数据泄漏、把正常等待当停滞、将纠正数据当错误清除。保留原始失败并通过掩码与标签控制训练用途，默认不把失败动作当正确行为克隆目标

**创新空间**：针对耦合灵巧手的阶段敏感质量指标，以及带证据的操作员反馈。需与简单平滑／越界规则、随机等量选择和全部数据比较；反馈研究采用同人交叉或随机分组，避免把操作者差异误判为方法因果效果

## 方案 C：科研增强版——物理可行性与目标数据价值联合优化

**参考**：[[02_论文/08_数据与遥操作/SPIDER - Scalable Physics-Informed Dexterous Retargeting|P209 · SPIDER]] 的物理采样、[[02_论文/08_数据与遥操作/MimicGen - A Data Generation System for Scalable Robot Learning using Human Demonstrations|P202 · MimicGen]]／[[02_论文/08_数据与遥操作/DexMimicGen - Automated Data Generation for Bimanual Dexterous Manipulation via Imitation Learning|P145 · DexMimicGen]] 的源示范扩增、[[02_论文/08_数据与遥操作/Quality over Quantity - Demonstration Curation via Influence Functions for Data-Centric Robot Learning|P206 · QoQ]] 的目标相关效用、[[02_论文/08_数据与遥操作/TUCO - Curating Simulation Demonstrations for Sim-to-Real Robot Policy Co-Training|P207 · TUCO]] 的互补覆盖；[[02_论文/04_灵巧操作/LUCID - Learning Embodiment-Agnostic Intent Models from Unstructured Human Videos for Scalable Dexterous Robot Skill Acquisition|P188 · LUCID]] 提供任务意图与本体控制分离的另一思路

**硬件**：可靠 DH116 动力学／碰撞模型、可用 GPU 模拟环境，后续才需要已验收臂手系统及额外观察。完整复制某论文的多相机、手型和预训练预算并非前提，应先复用其可检验的单个模块

**软件模块**：小规模源示范 → 物体几何及接触阶段 → 耦合约束下物理修正 → 改变布局／摩擦等生成候选 → 有效性和多样性审计 → 用少量目标执行估计效用／覆盖 → 小型策略训练 → 独立分布变化测试。源数据和目标数据统一动作语义后再混合

**最小可验证实验（拟议）**：在单个三指抓取模拟任务中，固定源示范与训练预算，依次比较纯运动学、物理修正、物理修正＋随机扩增、物理修正＋效用／覆盖筛选。将视觉扰动与接触动力学扰动分开，分别测物体跟踪、穿透／滑落、生成保留率、下游闭环成功率和总 GPU 时间

**主要风险**：过于理想的模型、只保留成功轨迹造成覆盖偏差、目标参考过少、浮动手动作机械臂不可达。真机迁移应分阶段测量，不把仿真成功或离线开环回放写成鲁棒闭环策略；新版本参考或公开数据的指标分母要留存

**创新空间**：接触阶段的不确定性如何决定采样预算，以及“物理可行但训练无用”的数据怎样被识别。跨本体研究可用 DH116 主动轴约束与另一本体模型做离线对照；如果只有一个真实手，不能声称已经完成跨真机泛化

## 最值得先切入的三个问题

1. **耦合结构下的可信重定向**：同时知道哪些目标看不清、哪些目标做不到，区别感知和映射失败
2. **接触阶段的数据质量**：必要停顿和恢复动作与无效抖动怎样区分；按独立策略收益评价，而不是只追求轨迹短
3. **少量真实证据指导合成数据组合**：在固定采集和训练预算下，怎样保留互补的抓取／纠正状态，并明确模拟与现实差距

建议执行顺序 A → B → C。先建立可靠记录与可重复基线，再增加物理生成和大模型；是否构成创新以公开基线、控制变量和新实验结果判断，不以使用了更多模型名称判断
