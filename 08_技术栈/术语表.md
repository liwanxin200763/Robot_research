# 机器人学习术语速查

先记住三个问题：这个量属于哪个坐标系？单位是什么？多久更新一次？读论文或代码时，如果这三点不清楚，后面的动作含义也不清楚。

| 英文术语 | 中文解释 |
|---|---|
| Joint | 关节：机械臂可转动或平移的连接处；程序通常读取其角度或位移。 |
| DoF | 自由度：能独立控制的运动维度。七关节机械臂通常有七个手臂自由度。 |
| Flange | 法兰：机械臂末端安装工具的机械连接面。 |
| End-Effector | 末端执行器：装在末端的工具，例如普通夹爪。 |
| TCP | 工具中心点：控制和标定时使用的工具参考点，未必与法兰重合。 |
| Position / Orientation | 位置表示“在哪里”；姿态方向表示“朝向哪里”。 |
| Pose | 位姿：位置加朝向，必须说明相对于哪个坐标系。 |
| FK / IK | 正运动学由关节值计算 TCP 位姿；逆运动学由目标位姿求可行关节值。 |
| Observation | 观测：策略当前看到的图像、深度、关节状态、语言等。 |
| Robot State | 机器人状态：关节位置、速度、夹爪状态，必要时还包括力。 |
| Action | 动作：策略输出的控制命令，可能是关节目标或末端位姿增量。 |
| Action Space | 动作空间：命令的维度、单位、范围、坐标系和更新频率。 |
| Trajectory | 轨迹：按时间排列的状态和动作。 |
| Episode | 回合：从复位到任务结束的一次尝试。 |
| Teleoperation | 遥操作：人通过手柄、主从臂等装置实时控制机器人。 |
| Demonstration | 示范：记录下来的专家操作样例；可以成功，也可以标注为失败。 |
| Dataset | 数据集：带格式、元数据、划分和来源信息的一组回合。 |
| Imitation Learning | 模仿学习：从示范中学习策略。 |
| Behavior Cloning | 行为克隆：把专家动作当作监督标签来训练策略。 |
| ACT | Action Chunking with Transformers：一次预测一小段后续动作，并处理连续预测之间的衔接。 |
| Action Chunk | 动作块：一起生成的多个未来动作，而非只预测下一步。 |
| Diffusion Policy | 扩散策略：从噪声出发，逐步生成可执行动作序列。 |
| Flow Matching | 流匹配：学习把噪声连续变换为动作样本的方向场。 |
| VLA | Vision-Language-Action：输入视觉信息和语言目标，输出机器人动作的模型。 |
| Planning | 规划：选择目标或技能的先后顺序；仍需要底层策略执行。 |
| Grounding | 落地/对齐：把语言中的物体、位置和动作指向当前真实场景。 |
| Affordance | 可供性/可执行性：在当前状态下，某个技能是否有可能成功。 |
| Skill | 技能：可复用的行为，例如抓取、放置、开抽屉。 |
| Value Function | 价值函数：估计当前状态或动作的未来收益；SayCan 用它帮助判断技能是否可执行。 |
| Generalization | 泛化：面对训练中未见过的物体、场景或任务仍能工作。 |
| Cross-Embodiment | 跨本体泛化：在不同机械结构、传感器或动作空间的机器人之间迁移。 |
| Sim2Real | 仿真到现实迁移：在仿真中学到的策略到真机上还能执行。 |
| Failure Detection | 失败检测：发现执行偏离了计划或任务已经失败。 |
| Failure Recovery | 失败恢复：检测后采取安全纠正动作。 |
| Replanning | 重新规划：根据更新后的状态重新安排后续技能或任务步骤。 |

本项目用双臂和普通夹爪，尤其要留意两臂同步、共同接触物体、碰撞约束，以及动作解码是否与真实控制器一致。
