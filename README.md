# 机器人科研文献库

这是一个面向机器人学习研究的文献库，使用 Obsidian Markdown 组织论文卡片、分类索引和阅读笔记，并使用 Excel 保存结构化元数据。

主要方向：

- VLA（Vision-Language-Action）
- 机器人操作
- 双臂操作
- 灵巧操作
- 仿真到现实（Sim2Real）
- Diffusion / Flow / IL / RL
- 泛化与长时程任务
- 机器人数据与遥操作

## 从这里开始

首先查看 [00 开始这里/00 首页.md](00%20%E5%BC%80%E5%A7%8B%E8%BF%99%E9%87%8C/00%20%E9%A6%96%E9%A1%B5.md)，从入口页进入分类索引和论文主卡。

## Obsidian

1. 克隆或下载本仓库。
2. 打开 Obsidian。
3. 选择“将文件夹作为库打开”（Open folder as vault）。
4. 选择仓库根目录。
5. 从 `00 开始这里/00 首页.md` 开始浏览。

## 结构化数据库

结构化数据库位于：

`01 论文文库/Paper_Pool.xlsx`

Excel 用于去重、筛选、统计和维护结构化字段；Obsidian 用于日常浏览论文卡片、分类入口、内部链接和阅读笔记。论文卡片不代表已经精读。

## 文献库结构

- `00 开始这里/`：首页与阅读入口
- `01 论文文库/`：正式主库、论文索引、PDF 与 Excel 数据库
- `02 研究方向/`：研究方向索引
- `03 论文卡片/`：按原有主分类存放的规范论文卡片
- `04 项目与实验/`：项目概览、代码入口、实验流程、最小复现路线与研究问题
- `05 检索与引用/`：正式检索方法、关键词、会议期刊与引用资料
- `06 使用说明/`：知识库使用说明

原有基准、技术准备、研究问题与模板等辅助资料继续保留，可由页面链接访问。旧导航文档保留兼容入口。Obsidian 使用原生文件名升序排列，不需要社区排序或 Folder Notes 插件。

## 论文信息与来源

论文卡片提供目前整理出的信息，并不代表论文已经精读。发现池中的记录可能只整理了元数据或摘要。代码公开也不代表已在本地成功复现。

主卡保留论文链接、项目主页、官方代码和引用量来源。可通过[按引用量排序](05%20%E6%A3%80%E7%B4%A2%E4%B8%8E%E5%BC%95%E7%94%A8/%E6%8C%89%E5%BC%95%E7%94%A8%E9%87%8F%E6%8E%92%E5%BA%8F.md)浏览文献；尚未人工核验的引用量保持待核验。

本地 PDF 见 [PDF 索引](01%20%E8%AE%BA%E6%96%87%E6%96%87%E5%BA%93/PDFs/%E6%9C%AC%E5%9C%B0PDF%E7%B4%A2%E5%BC%95.md)；暂缺文件见[缺失 PDF 清单](01%20%E8%AE%BA%E6%96%87%E6%96%87%E5%BA%93/PDFs/%E7%BC%BA%E5%A4%B1PDF%E6%B8%85%E5%8D%95.md)。

正式发表信息、代码、数据和实验结论应优先依据论文正式页面、作者项目页和官方代码仓库。缺乏可靠来源的信息不显示相应字段，也不根据标题或二手资料推断。

## 维护范围

仓库公开维护研究索引、结构化元数据和原创阅读笔记。仅将已确认可再分发的论文 PDF 纳入版本控制；其他论文 PDF 保存在本地，不上传公开仓库。模型权重、数据集、克隆的第三方 Git 仓库、本地应用状态和历史备份不纳入版本控制。
